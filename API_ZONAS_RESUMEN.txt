🔌 ENDPOINTS API REST
─────────────────────────────────────────────────────────────────────────────
  ✓ GET  /api/zones/info                    → Información de la API
  ✓ GET  /api/zones/estados                 → Listar todos los estados
  ✓ GET  /api/zones/ciudades/<estado>       → Ciudades por estado
  ✓ GET  /api/zones/municipios/<estado>     → Municipios por estado
  ✓ GET  /api/zones/colonias/<cp>           → Colonias por código postal
  ✓ GET  /api/zones/buscar?q=<texto>&campo= → Buscar por texto
  ✓ POST /api/zones/validar                 → Validar dirección

📱 USO EN APLICACIÓN
─────────────────────────────────────────────────────────────────────────────

Validación de Direcciones:
  from models.estados import validar_codigo_postal_mexico
  
  es_valido = validar_codigo_postal_mexico(
    '01001',                    # Código postal
    'Ciudad de México',         # Estado
    'San Ángel'                 # Colonia
  )

Búsqueda Manual:
  from api_zonas import get_zones_api
  
  api = get_zones_api()
  colonias = api.get_colonias_por_cp('01001')
  estados = api.get_estados()
  resultados = api.buscar_por_texto('santa', 'colonia')

Frontend:
  <script src="{{ url_for('static', filename='js/zones-api.js') }}"></script>
  
  const colonias = await zonesAPI.getColonias('01001');
  const valido = await zonesAPI.validar('01001', estado, colonia);
