## Endpoints Útiles

### Obtener colonias (lo más importante)
```
GET /api/zones/colonias/01001
```

### Validar dirección
```
POST /api/zones/validar
Content-Type: application/json

{
  "codigo_postal": "01001",
  "estado": "Ciudad de México",
  "colonia": "San Ángel"
}
```

### Buscar
```
GET /api/zones/buscar?q=santa&campo=colonia
```

## Uso en Python

```python
from api_zonas import get_zones_api

api = get_zones_api()

# Obtener colonias
colonias = api.get_colonias_por_cp('01001')
for c in colonias[:5]:
    print(c['colonia'], '-', c['municipio'])

# Validar dirección
valido, info = api.validar_codigo_postal('01001', 'Ciudad de México', 'San Ángel')
print("Válido:", valido)

# Buscar
resultados = api.buscar_por_texto('santa fe', 'colonia')
print(f"Encontrados {len(resultados)} resultados")
```

## Cómo Funciona en Formularios

1. Usuario ingresa código postal → `#codigo_postal`
2. JavaScript lee el valor y llama a `/api/zones/colonias/{cp}`
3. Se actualiza automáticamente el select `#colonia`
4. Al enviar el formulario, se valida localmente
5. El servidor valida nuevamente (doble validación)

## Solución de Problemas

### "No se cargan las colonias"
1. Abre las developertools del navegador (F12)
2. Ve a la pestaña Network
3. Ingresa un CP en el formulario
4. Deberías ver una llamada a `/api/zones/colonias/XXXXX`
5. Verifica que retorna datos

### "Error: API no encontrada"
1. Reinicia Flask
2. Asegúrate de que `api_zonas/` existe en la raíz del proyecto
3. Revisa que la importación en `app.py` está presente

### "Código postal no válido aunque existe"
1. El CP debe tener exactamente 5 dígitos
2. Se rellenan automáticamente con ceros (999 → 00999)
3. Verifica que el estado y colonia coincidan

**¿Funciona offline?**  
Sí, completamente. La API es local.

**¿Cuántos registros tiene?**  
156,940 registros de direcciones mexicanas únicos.

**¿Cubre todo México?**

**¿Puedo modificar los datos?**  
Sí, el XML está en `api_zonas/data/CPdescarga.xml`
