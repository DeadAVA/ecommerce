 💻 CÓMO USAR

1. INSTALAR DEPENDENCIAS:
   pip install -r requirements.txt
   # Ahora incluye PyJWT

2. ACTUALIZAR requirements.txt:
   ✓ Ya está hecho (PyJWT==2.8.1 agregado)

3. USAR AUTENTICACIÓN JWT:

   En rutas protegidas:
   ────────────────────
   from utils.auth import token_required
   
   @app.route('/api/datos')
   @token_required
   def obtener_datos():
       usuario_id = request.user_id
       usuario_email = request.user_email
       # ...

4. USAR JAVASCRIPT:

   Validación automática de formularios:
   ──────────────────────────────────────
   <form>
       <input type="email" required>
       <input type="password" required>
       <button type="submit">Login</button>
   </form>
   <!-- App valida automáticamente -->

   API calls con tokens automáticos:
   ──────────────────────────────────
   const result = await app.api('/api/endpoint');
   // Cookies se incluyen automáticamente

5. REFRESCAR TOKEN:
   
   Automático:
   ───────────
   // Cada 25 minutos, el sistema refuerza el token
   // Usuario no ve nada

 📊 COMPARATIVA: ANTES vs DESPUÉS
═══════════════════════════════════════════════════════════════════════════════

SEGURIDAD:
┌────────────────────────┬──────────────┬──────────────┐
│ Aspecto                │ ANTES ❌     │ DESPUÉS ✅   │
├────────────────────────┼──────────────┼──────────────┤
│ Almacenamiento         │ localStorage │ Cookies      │
│ XSS Protection         │ No           │ HttpOnly     │
│ CSRF Protection        │ No           │ SameSite     │
│ Expiración automática  │ No           │ Sí (30 min)  │
│ Refresh de token       │ Manual       │ Automático   │
│ Control servidor       │ No           │ Sí           │
│ HTTPS                  │ No           │ Sí (Secure)  │
└────────────────────────┴──────────────┴──────────────┘

DISEÑO:
┌────────────────────────┬──────────────┬──────────────┐
│ Aspecto                │ ANTES ❌     │ DESPUÉS ✅   │
├────────────────────────┼──────────────┼──────────────┤
│ Estilos                │ Básicos      │ Profesional  │
│ Responsivo             │ Parcial      │ Mobile-first │
│ Componentes            │ None         │ Reutilizable │
│ Transiciones           │ No           │ Suaves       │
│ Color scheme           │ Sin definir  │ Profesional  │
│ Validación formularios │ Básica       │ Avanzada     │
│ Notificaciones         │ Flash simple │ Profesional  │
