═══════════════════════════════════════════════════════════════════════════════
 ERRORES COMUNES Y SOLUCIONES
═══════════════════════════════════════════════════════════════════════════════

❌ "Permission denied" puerto 443
   → Ejecuta como Administrador
   → O usa puerto diferente en app.py

❌ "No such file or directory: certs/cert.pem"
   → Ejecuta: python generate_certs.py

❌ Certificado no válido (aviso del navegador)
   → Normal con certificados autofirmados
   → Click en "Avanzado" → "Continuar a localhost"

❌ Base de datos no conecta
   → Verifica DATABASE_URI en .env
   → Asegúrate que MySQL está corriendo

❌ Correos no se envían
   → Verifica MAIL_USERNAME y MAIL_PASSWORD
   → Para Gmail usa contraseña de aplicación
   → https://support.google.com/accounts/answer/185833

VER: INICIO_RAPIDO.txt para más soluciones
